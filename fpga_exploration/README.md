# FPGA Acceleration Exploration

This directory documents the exploration of FPGA-based acceleration frameworks
for neural network inference, with a focus on understanding deployment
constraints and system-level trade-offs for embedded AI.

## Contents

- BNN-PYNQ/  
  Experiments and reference designs based on the BNN-PYNQ framework for deploying
  binarized neural networks on FPGA platforms.

- bnn/  
  Supporting scripts, configuration files, and experimental artifacts related
  to binarized neural network exploration.

## Scope of Work

The work in this directory represents exploratory investigation rather than a
fully optimized deployment. The focus was on:

- Understanding FPGA toolchains for ML acceleration
- Evaluating feasibility of CNN/BNN inference on FPGA platforms
- Identifying constraints related to precision, resource usage, and deployment
  complexity

These explorations inform later performance comparisons and design trade-offs
between software-based and FPGA-oriented implementations.

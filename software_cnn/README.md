# CNN-Based Lung Cancer Image Classification

This directory contains the software implementation of convolutional neural
networks (CNNs) for lung cancer image classification. The focus is on model
design, supervised training, and evaluation using medical imaging data.

## Contents

- notebooks/  
  Jupyter notebooks used for data preprocessing, model training, and
  experimental evaluation of CNN architectures.

- lung_data_set/  
  Medical image dataset used for training and validation. The dataset is
  organized according to class labels and preprocessing requirements.

## Technical Focus

- Convolutional Neural Networks (CNNs)
- Supervised learning with medical imaging data
- Model training, validation, and accuracy evaluation
- Preparation of models for potential deployment on embedded platforms

This software implementation serves as the baseline for later exploration of
hardware acceleration using FPGA-based solutions.
